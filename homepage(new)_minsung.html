Projects

👥 ML기반 악성 URL 판별 서비스 (프로젝트 링크)

개요: 2023.3 ~ 2023.10 / 팀 5명 | 포지션: 데이터 수집, 전처리, 모델링 | 성과: 한국융합보안학회 2023 하계 학술대회 장려상 수상

Kaggle, OpenPhish에서 최신 악성 URL 데이터를 수집, 분석하여 악성 URL로 인해 발생가능한 피해를 최소화 하는것을 목표로 프로젝트 기획. URL의 유효 특징값 추출 후 복수 모델에서 다중 다수결 방식으로 예측 결과를 도출, OpenPhish에서 실시간 크롤링하여 데이터셋을 자동 최신화후 파인튜닝 적용하는 부분 주도.

엔지니어적인 부분뿐만 아니라 규칙 기반의 기호·패턴 구조를 갖는 URL 특성에 맞게 전처리 설계와 특징값 선별 등의 데이터 구조 분석 및 연구에도 많은 시간을 소요해 예측 성능 확대. 모델링 과정속 데이터 맥락 파악의 중요성 인지 및 경험.

Overfitting 문제를 해결하기 위해 특징값의 학습 기여도 분석 및 정규화 적용, 최신 URL 패턴 연구논문을 참고한 특징값 선별로 모델 경량화 및 일반화 성능 향상 시도. URL 특징값 추출 후 DT, KNN, GNB, MLP, RF 등 다중 모델을 테스트, 다수결 방식으로 예측 결과 도출. Random Forest 기반 앙상블로 93.86% 정확도 달성.

Airflow 미적용으로 단순 time 모듈 기반 자동화에 한정, DB 연동 미구현. 향후 Airflow를 활용한 재학습 파이프라인과 서비스 배포 계획.

[주요 기술] 언어 및 환경: Python, Google Colab (TPU 활용) | 데이터 처리: pandas, NumPy | 크롤링: requests, BeautifulSoup, urllib | 모델링: scikit-learn (Random Forest, Stacking, SVM, ...), joblib | 시각화: matplotlib, seaborn

👥 무신사 리뷰 종합 및 분석 서비스 (프로젝트 링크)

개요: 2025.1~2025.3 / 팀 4명 | 포지션: 기획, 데이터 수집, 감성분석 모델링

무신사를 비롯한 쇼핑몰 사이트의 리뷰 데이터를 실시간 자동으로 수집,분석하여 모니터링하고 결과를 시각화된 대시보드와 LLM을 활용한 피드백 형태로 제공하여 쇼핑몰 운영자 혹은 판매자의 매출 증진에 기여하기 위한 프로젝트.

기획, 데이터 수집, AI 아키텍처 설계 및 구현, 산출물 관리, 서비스 개발(EC2,FE,BE)과 배포(AWS)까지의 전반적 과정 경험. 크롤링+전처리(pyspark)+적재(MySQL) 과정 airflow DAG자동화 → 크롤링 기능 개발 및 토픽, 분석 모델을 적용한 결과를 DB 적재하여 저장하는 과정까지의 파이프라인 설계 참여.

감성분석 모델링 과정 주도, 리뷰 데이터의 특성에 맞게 Google Natural Language API를 활용해 일관적인 감성 분석 라벨링을 진행, FocalLoss로 긍정의 비율이 높은 리뷰 데이터의 불균형을 처리. KoBERT모델 베이스로 성능 확보.

학습 과정에서 EC2인스턴스에서 할당된 GPU VRAM용량이 초과되어 OOM에러 발생, torch.cuda.amp 모듈로 소모되는 GPU자원을 축소하여 최적화 및 관련 문제 해결.

무신사의 1977개 제품, 56만개의 리뷰 데이터 분석 결과 / 감성 분석 모델(KoBERT기반) acc 93%, 서비스 특성에 맞게 부정 데이터에 대한 예측 성능에 집중(Bad acc 97%) / 토픽 분석 모델(KLUE-BERT기반) acc 95% 정확도 달성.

chart.js를 활용한 시각화 자료, OpenAI LLM api을 활용한 피드백 자료를 생성. 네이버 스토어 등 다중 쇼핑몰/제품군 점차 확장 계획, 볼륨이 큰 프로젝트 진행시 단순 버전에 따른 코드 공유가 아닌 GitHub Flow 기반 CI/CD 파이프라인 도입으로 협업 효율화 개선 필요성 인지.

[주요기술] 언어 및 환경: Python, Anaconda, Jupyter, Visual Studio Code(Ubuntu) | 크롤링: Selenium, BeautifulSoup, Chrome | 데이터 파이프라인: Apache Airflow(DAG), PySpark , Hadoop/HDFS, Redis | 데이터베이스: MySQL | 모델링: PyTorch (KoBERT,KLUE-BERT), Hugging Face, CUDA/cuDNN | 웹 서비스: FastAPI, WebSocket, Chart.js(시각화), HTML/JS/CSS (UI) | 클라우드/배포: AWS EC2
